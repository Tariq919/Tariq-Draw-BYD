# Tariq Draw

تطبيق رسم بسيط لشاشات أندرويد في سيارات BYD. اختر قلمًا ولونًا وابدأ الرسم بإصبعك. يعمل دون إنترنت، ولا يحتاج روت أو ADB.

**حالة التحميل:** ملف التثبيت جاهز، لكن رفعه إلى هذا المستودع لم يكتمل بعد. لا يوجد APK قابل للتحميل من المستودع حاليًا.

## التثبيت

1. انقل ملف APK إلى USB.
2. افتحه من مدير ملفات السيارة.
3. اسمح بالتثبيت من هذا المصدر إذا طلب النظام ذلك، ثم اضغط «تثبيت».

بعض إصدارات BYD تمنع تثبيت التطبيقات الخارجية. التطبيق لا يتجاوز هذه القيود. يحتاج أندرويد 6 أو أحدث وAndroid System WebView يدعم Pointer Events.

## الاستخدام

- اختر القلم أو الممحاة أو إحدى أدوات الأشكال، ثم اختر اللون والحجم.
- استخدم «تراجع» و«إعادة» لتعديل خطواتك. يمكن التراجع حتى بعد مسح اللوحة.
- اضغط «حفظ» للاحتفاظ بنسخة قابلة للتعديل في «رسوماتي»، أو اختر «تصدير صورة» لحفظ PNG في المكان الذي تحدده.
- عملك الحالي يُحفظ تلقائيًا. صدّر الصور المهمة قبل حذف التطبيق.
- من الإعدادات يمكنك تغيير اللغة أو تفعيل الإضاءة الخافتة.

اللغات: العربية، الإنجليزية، الفرنسية، الصينية، الهندية، الأردية، الفارسية، والتركية.

يظهر تنبيه عند الفتح، دون قفل تلقائي أثناء الحركة. للسائق: استخدم الرسم بعد التوقف. يمكن للراكب استخدامه أثناء الرحلة. قيود نظام السيارة تبقى سارية.

الإصدار 1.0.0. نجحت فحوص البناء والتوقيع والرسم والحفظ والتصدير واللغات على خمسة مقاسات للشاشة. لم يُختبر على سيارة BYD فعلية بعد. تطبيق مستقل وغير تابع لشركة BYD.

## English

Tariq Draw is a simple drawing app for Android-based BYD screens. It works offline and needs no root or ADB.

**Download status:** the installer is ready, but the upload to this repository is incomplete. No APK is available from this repository yet.

**Install:** copy the APK to USB and open it in the car's file manager. Allow installation from that source if prompted, then tap Install. Some firmware versions block third-party apps; this app does not bypass those restrictions. Android 6+ and a System WebView with Pointer Events support are required.

**Draw:** choose a pen, marker, eraser, line, rectangle or circle, then choose a color and size. Undo and redo work after clearing too. Save keeps an editable copy in My drawings. Export image saves a 1600 × 900 PNG wherever you choose. Your current work saves automatically. Export important images before uninstalling.

Settings include dim screen and eight languages: Arabic, English, French, Chinese, Hindi, Urdu, Persian and Turkish.

A reminder appears at launch; there is no app-level motion lock. Drivers should draw after parking. Passengers may use the app during a journey. Vehicle restrictions still apply.

Version 1.0.0. Build, signing, drawing, saving, export and language checks passed across five screen sizes. Physical BYD testing is still needed. This is an independent app, not a BYD product.

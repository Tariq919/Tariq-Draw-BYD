# Tariq Draw

تطبيق رسم بسيط لشاشات أندرويد في سيارات BYD. اختر قلمًا ولونًا وابدأ الرسم بإصبعك. يعمل دون إنترنت، ولا يحتاج روت أو ADB.

## التحميل والتثبيت

1. حمّل [ملف التطبيق](Tariq-Draw-v1.0.0.apk?raw=true).
2. انقله إلى السيارة عبر USB، ثم افتحه من مدير الملفات.
3. اسمح بالتثبيت من هذا المصدر إذا طلب النظام ذلك، ثم اضغط «تثبيت».

بعض إصدارات شاشات BYD تمنع تثبيت تطبيقات خارجية. التطبيق لا يتجاوز هذه القيود. يحتاج أندرويد 6 أو أحدث، ومكوّن Android System WebView يدعم اللمس بالقلم أو الإصبع.

## الاستخدام

- اختر أداة الرسم ولونها وحجمها من جانبي الشاشة.
- استخدم «تراجع» لإلغاء آخر خطوة، و«إعادة» لاسترجاعها. حتى مسح اللوحة يمكن التراجع عنه.
- اضغط «حفظ» للاحتفاظ بنسخة قابلة للتعديل في «رسوماتي»، أو اختر «تصدير صورة» لحفظها بصيغة PNG في المكان الذي تحدده.
- عملك الحالي يُحفظ تلقائيًا. حذف التطبيق يحذف الرسومات الموجودة داخله، لذلك صدّر الصور التي تريد الاحتفاظ بها.
- من الإعدادات يمكنك تغيير اللغة أو تفعيل الإضاءة الخافتة.

اللغات: العربية، الإنجليزية، الفرنسية، الصينية، الهندية، الأردية، الفارسية، والتركية.

يظهر تنبيه عند فتح التطبيق، ولا يفرض التطبيق قفلًا تلقائيًا أثناء الحركة. للسائق: استخدم الرسم بعد التوقف. يمكن للراكب استخدامه أثناء الرحلة. قيود نظام السيارة، إن وجدت، تبقى سارية.

الإصدار 1.0.0. أُجري فحص للبناء والتوقيع ووظائف واجهة الرسم. لم يُختبر على شاشة BYD فعلية بعد. تطبيق مستقل وغير تابع لشركة BYD.

## English

Tariq Draw is a simple drawing app for Android-based BYD screens. Choose a tool and color, then draw with your finger. It works offline and needs no root or ADB.

**Install:** download the [APK](Tariq-Draw-v1.0.0.apk?raw=true), copy it to the car using USB, and open it in the file manager. Allow installation from that source if prompted. Some BYD firmware versions restrict third-party installation; this app does not bypass those restrictions. Android 6 or later and a System WebView with Pointer Events support are required.

**Draw:** choose a pen, marker, eraser, line, rectangle or circle. Undo and redo also work after clearing the canvas. Save keeps an editable copy in My drawings. Export image saves a 1600 × 900 PNG to a location you choose. Your current drawing saves automatically. Uninstalling removes internal drawings, so export any images you want to keep.

**Settings:** change the language or dim the screen. Arabic, English, French, Chinese, Hindi, Urdu, Persian and Turkish are included.

A reminder appears at launch. The app adds no automatic motion lock. Drivers should draw after parking; passengers may use it during a journey. Vehicle restrictions still apply.

Version 1.0.0. Build, signing and drawing UI checks have been completed. Physical BYD testing is still needed. This is an independent app, not a BYD product.
